怎么用

  1. 解压。把整个文件夹放到硬盘上（比如 D 盘）。别只把 exe 单独拖出来 —— 旁边那些文件是程序本体，缺一个都跑不起来。
  2. 双击文件夹里的「运动世界校园-东秦助手.exe」，进「设置与登录」页填手机号 + 密码（就是平时 App 登录的那个）。城市和坐标已经预填好，高德 Key 可以留空，点「登录」。
  3. 回「跑步」页用默认的自动参数，点「在线预览」看一眼路线，没问题点「提交此方案」。跑完到「记录与诊断」页确认成绩上传成功。

配一个高德 Key（可选）

不配也能跑。配了以后「校园环」会走高德的步行路径规划，沿真实道路绕行；不配就按打卡点顺序直线拼接。两种都能正常提交，只是直线版看起来不太像人跑出来的。

最容易踩的坑：平台必须选「Web服务」。 控制台里那六个选项 —— Android平台、iOS平台、Web端(JS API)、Web服务、智能硬件、微信小程序 —— 选成 Android，页面会要求填「发布版安全码 SHA1」「PackageName」，那是安卓 App 签名才有的东西，本程序没有也不需要，卡在这一栏不是你操作错了。

  1. 打开 高德开放平台控制台 · 我的应用，手机号或支付宝登录。
  2. 还没有应用就点「创建新应用」，应用名随便填（比如「校园跑」），类型选出行或工具都行。
  3. 在应用那一行点「添加 Key」：Key 名称随便填，服务平台选「Web服务」，勾选协议，点「提交」。
  4. 列表里会出现一串 32 位字符（字母+数字），复制它。
  5. 打开软件 →「设置与登录」页 →「高德 Key」输入框 → 粘贴 →「保存设置」。回「跑步」页点「在线预览」，路线能沿路生成就成功了。
现象原因
提示 Key 无效用了 Android 或 Web端(JS API) 的 Key。后者是给网页用的，同样不行，必须是「Web服务」。
提示超额 QUOTA当天免费额度用完了，隔天恢复。
能不能共用别共用。额度算在你号上，滥用被封也是封你的。要分享软件就让人自己申请，两分钟的事。
换电脑要重申请吗不用，同一个 Key 长期有效。软件配置在程序目录的 .funsport 文件夹里，一起拷走就不用重填。

压缩包里也带了一份纯文字版：高德Key申请教程.txt，离线看这个。

和原版有什么区别

原项目要自己装 Python、装依赖、跑命令行配置向导。这版把那些全消掉了：

项目原版这版
运行环境装 Python 3.8+ 和 5 个依赖解压双击，不用装任何东西
配置命令行回答 6 个问题只填手机号 + 密码，其余预设
学校坐标手动填写已预设东秦，登录后按打卡点自动校准
高德 Key不填校园环生成会失败可留空，自动走备用路线
崩溃排查控制台报错自动写 crash.log，发给我就能定位

用之前要知道的

时间窗口是硬限制：不在学校规定的有效时段内提交，服务器直接拒绝。软件会提示，但改不了这条。

人脸识别那一步得你自己在手机上过，软件只负责生成和提交轨迹，绕不过去。

第一次先小量试：建议只提交 1 公里左右，确认能正常上传再加量。

出问题看日志：程序文件夹里的 boot.log 每次启动都会写，crash.log 只有崩了才出现。把 crash.log 发过来我照着重打一版。

这是对开源项目的本地化打包，仅供学习交流与编程实践参考。用它代跑校园跑属于绕开考核，学校的规则自己掂量，后果也自己担。
