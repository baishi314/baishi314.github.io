    怎么用

    1. 总览里每块是一个领域。从最左边一列标着“可以开始”的领域入手；下面“现在能学”已经按重要性排好。
    2. 点一个领域进入它的技能地图；点一个技能看它学什么、去哪学、练习题，以及它的前置链。
    3. 学会后点“点亮”。必须前置没点亮的技能是锁着的；点亮前置后它会自动解锁。
    4. 想直奔某个方向：选上面的路线，或在技能详情里点设为目标，左边会排出要学的顺序；不想要了点计划旁的“取消目标”，或把路线选回“自由探索”。

        使用说明

        • 总览：每块是一个领域，连线是领域之间的必须前置（线越粗条数越多）。点一块进入它的技能地图，点“下一步”直接打开该领域现在最值得学的技能。
        • 目标与路线：在技能详情里点“设为目标”，或在上面选一条路线，左边会按顺序列出要学的技能。取消：再打开那个技能点“取消目标”，或点左边计划旁的“取消目标 / 退出路线”，或把路线选回“自由探索”。
        • 步骤：横轴“第 N 步”= 前面至少有 N−1 层必须前置。同一步里的技能互不依赖，可以按兴趣挑。
        • 必须前置：真实大学课程把它列为先修，并且不会它就学不懂入门内容。没点亮就不能点亮下一个。标着“待核实”的是按常见课程体系起草、还在找课程证据的。
        • 推荐前置：有些课程建议先学、或只在深入层才用到。只提示，不挡路。
        • D1–D4：D1 核心基础、D2 工程实践、D3 专业深入、D4 高级理论与科研。卡片上的标记是这个技能的入门层；练习题按入门层出。
        • 操作：拖动平移，滚轮或双指缩放；单击技能看详情，双击技能打开知识导览图；Tab 在技能间移动，回车看详情，G 打开知识导览图，L 点亮/取消，Esc 取消选择（再按一次回到总览），/ 搜索，0 适应屏幕。浏览器的后退键可以回到上一个视图。
        • 进度只保存在这个浏览器里；换设备前用“进度 ▾ → 导出”备份。
