高德 Key 申请教程（可选，但建议配一个）
========================================

一、这是干什么用的
------------------
软件在生成「校园环」路线时，会调高德的「步行路径规划」接口，让它沿真实道路算路，
而不是把打卡点用直线连起来。配了 Key 走真实道路，没配就走直线兜底 —— 两种都能提交，
只是直线版绕起来不像人跑出来的。

所以：不填也能用。卡在这一步不值得，先跑起来更要紧。


二、最容易踩的坑（先看这条）
----------------------------
高德控制台上「服务平台」有六个选项：Android平台、iOS平台、Web端(JS API)、
Web服务、智能硬件、微信小程序。

  必须选【Web服务】。

选了 Android平台，页面会要求你填「发布版安全码 SHA1」「调试版安全码 SHA1」「PackageName」，
这三个是安卓 App 签名才有的东西。本项目是 Windows 桌面程序，根本没有，也不该有。
（SHA1 那一栏填不出来不是你操作错了，是平台选错了。）


三、具体步骤
------------
1. 打开 https://console.amap.com/dev/key/app  用手机号或支付宝登录。

2. 如果还没有应用：点右上角「创建新应用」，应用名随便填（比如「校园跑」），
   应用类型选「出行」或「工具」都行，创建。

3. 在应用那一行点「添加 Key」（或「添加」）。
   · Key 名称：随便填，比如 dongqin
   · 服务平台：选 Web服务   ← 关键
   · 勾选「阅读并同意 高德地图开放平台服务协议 和 高德地图开放平台隐私权政策」
   · 点「提交」

4. 回到列表，刚建的那条 Key 后面会显示一串 32 位的字符（字母+数字），
   点「复制」按钮，或者手动选中复制。

5. 打开软件 →「设置与登录」标签页 → 找到「高德 Key」输入框 → 粘贴 → 点「保存设置」。

6. 回到「跑步」页点「在线预览」，如果路线能沿路生成，就配好了。

个人开发者有免费日额度，日常跑几次远够用，不用充钱。


四、常见问题
------------
Q: 提示 Key 无效 / 不合法？
A: 八成是把 Android 或 Web端(JS API) 的 Key 拿来用了。Web端(JS API) 是给网页用的，
   同样不行。回控制台确认「服务平台」那一列写的是「Web服务」。

Q: 一定要配吗？
A: 不用。留空时软件自动降级：校园环按打卡点顺序直线拼接，其余流程完全一样。

Q: 提示超额 / QUOTA？
A: 当天免费额度用完了，隔天恢复。或者去控制台看有没有别人也在用这个 Key。

Q: Key 能发给别人吗？
A: 别发。Key 绑在你账号上，别人用掉的额度算你的，滥用被封也是封你的号。
   真要分享软件，让对方自己去申请一个，两分钟的事。

Q: 换电脑 / 重装还要重新申请吗？
A: 不用，同一个 Key 一直有效。软件配置存在程序目录下的 .funsport 文件夹里，
   换电脑时把那个文件夹一起拷过去就不用重填了。


五、一句话总结
--------------
控制台 → 创建应用 → 添加 Key → 平台选【Web服务】→ 提交 → 复制 32 位字符串 → 粘进软件。
