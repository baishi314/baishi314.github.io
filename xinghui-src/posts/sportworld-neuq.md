跑校园跑这件事，每个学期总有那么一段时间把人绑住：早上六点半的操场、晚上十点半的风、还有手机上那句红色的「本次记录无效」。运动世界校园的问题不是它难用，而是它要求你真的在跑——快了判无效，慢了判无效，停太久也判无效，骑车还得担心轨迹太顺。

[FunSportWorld](https://github.com/Funrestan/FunSportWorld) 这个开源项目解决的就是这一环：用你自己的账号登录，按打卡点生成一条合理的轨迹直接提交，成绩正常入库。但它要你先装 Python、装五个依赖、跑命令行向导回答六个问题——对不写代码的人来说，光第一关就劝退了。

所以就有了这个双击就能跑的版本，预设顺手改成了东秦。从代码到这篇说明，这一整套都是 AI 独立做完的，作者没有参与其中任何环节。这篇记一下它省掉了什么、以及几个踩过的坑。

## 一、它到底省掉了哪一步

原版装完之后的完整流程是：配 Python 环境 → 装依赖 → 跑命令行配置向导 → 填学校坐标 → 填高德 Key → 才开始用。中间任何一步报错，信息都是给开发者看的。

这版的做法是把 Python 运行时和依赖一起打进产物，外面套一个 Tkinter 窗口。于是你要做的只剩三件：解压、双击、填手机号密码。

打出来的是目录版而不是单文件 exe。单文件版试过，稳定报 `Could not create temporary directory`，exe 连 Python 层都进不去。目录版没这问题，启动更快，所以那一堆文件不是垃圾，是程序本体。

## 二、几个实际用起来才知道的点

- **城市和坐标预填成东秦**：`秦皇岛市`，锚点 `39.939226, 119.602341`。锚点只是初始值，登录后会按你账号里真实的打卡点重新校准，以后就算换了校区一般也不用改。
- **高德 Key 可以不填**：填了之后「校园环」会走高德的步行路径规划，沿真实道路绕行；不填就按打卡点顺序直线拼接。两种都能正常提交，区别只是后者看起来不太像人跑出来的。
- **崩溃有日志**：`boot.log` 每次启动写一行，`crash.log` 只有崩了才出现，里面是完整 traceback。这也是这版补的几处之一——原版崩了只有控制台一行红字，收到「打不开」这种反馈基本没法排查。
- **配置跟着文件夹走**：账号和路线缓存存在程序旁边的 `.funsport` 目录里。换电脑把整个文件夹拷过去就还是登录状态，不用重填。
- **v2 修了时间窗口**：之前偶尔出现「方案生成成功、提交却被拒」，根因是起止时间落在学校有效跑步时段之外。现在生成方案时会先读当天的有效时段，把时间安排进窗口内。

## 三、下载和安装

下载：[sportworld-neuq-v2.zip](https://baishi314.github.io/downloads/sportworld-neuq-v2.zip)（32.6 MB，适配 Windows 10 / 11 64 位）

1. 解压。整个文件夹放到硬盘上，比如 `D:\运动世界校园-东秦助手\`。**别只把 exe 单独拖出来**，旁边那些文件缺一个都跑不起来。
2. 双击文件夹里的 `运动世界校园-东秦助手.exe`。第一次启动会慢几秒，正常。
3. 如果 Windows 弹「已保护你的电脑」，点「更多信息」→「仍要运行」。没有签名证书的 exe 都会这样，不是文件坏了。

## 四、用起来

1. 进「设置与登录」页，填手机号和密码——就是你平时登 App 的那个。城市坐标已经填好，高德 Key 留空也行，点「登录」，状态栏显示已登录就成。
2. 回「跑步」页，用默认的自动参数（2.8 km、配速 400 秒/公里、步频 160 步/分钟），点「在线预览」看一眼路线形状，觉得没问题点「提交此方案」。
3. 界面会自己刷新进度，跑完到「记录与诊断」页确认成绩上传成功。

第一次建议只提交 1 公里左右试一次，确认能正常入库再加量。别一上来就按 2.8 公里交。

## 五、几件必须提前知道的事

**时间窗口是硬限制。** 不在学校规定的有效时段内提交，服务器直接拒绝，软件只能提示你，改不了这条。

**人脸识别要你自己过。** 软件只负责生成和提交轨迹，那一步得你在手机上真的刷一次，绕不过去。

**高德 Key 如果配，平台一定选「Web服务」。** 控制台里的六个选项中，选成 Android 会让你填「发布版安全码 SHA1」和 PackageName，那是安卓 App 签名才有的东西，本程序不需要——卡在这一栏不是你操作错了。选成 Web端(JS API) 也不行，那是给网页用的。

**Key 别共用。** 额度算在你号上，滥用被封也是封你的号。要分享软件让人家自己申请，两分钟的事。

**别装在 Program Files 里。** `.funsport` 写不进去会回落到 `~/.funsport`，配置分散成两处，迁移麻烦。

功能说明、高德 Key 的申请流程、和原版的逐项对比都在[工具页](https://baishi314.github.io/sportworld.html)上。
