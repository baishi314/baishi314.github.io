## 你好呀，欢迎来到我的小窝 👋

这里是 **baishi314** 的个人空间。

之前一直想搞个地方放自己的东西，于是就有了这个站。
风格是从开源项目搬过来的，自己改了一些细节。

### 这里会放什么

- **文章** ：学习笔记、遇到的坑、解决办法
- **杂谈** ：碎片式的想法，随手记
- **说说** ：更短的日常记录
- **资源** ：好用的网站整理

### 技术栈

这个站用 **Next.js + React + Tailwind CSS** 搭建，静态导出后托管在 GitHub Pages。

欢迎随便逛逛 😊
