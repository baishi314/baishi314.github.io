折腾博客这件事，本身就是个坑。但坑归坑，还是想有个地方把东西沉淀下来。

## 为什么写

以前的东西散在各处：代码在 GitHub，笔记在本地，想法在聊天记录里。

时间一长，全找不着了。

## 打算写什么

大方向上就三类：

- **技术笔记** —— 踩过的坑、想明白的事
- **折腾记录** —— 自动化脚本、Minecraft 模组、各种小工具
- **随便写写** —— 没什么明确目的的思考

## 代码长这样

```python
def hello(name: str) -> str:
    return f"Hello, {name}!"

print(hello("baishi314"))
```

行内代码是这样的：`hugo server -D`。
