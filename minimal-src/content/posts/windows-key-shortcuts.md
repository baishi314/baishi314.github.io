绝大多数人按 Win 键只有一个目的：点开开始菜单找软件。这键于是常年在键盘左下角吃灰，旁边的 Ctrl 忙得要死，它闲得要命。

其实 **Win 是 Windows 里权限最高的修饰键**。Ctrl 的组合大多只在当前软件里生效（保存、查找、撤销），而 Win 的组合直接交给系统，任何软件都拦不住——所以截屏、锁屏、切桌面这类"应该随时可用"的功能，全都挂在它身上。

## 一、它到底在哪

![Windows 键的位置](/minimal/images/kb/kb-win-key.png)

标准 104 键键盘上，Win 键夹在**左 Ctrl 和左 Alt 之间**，右边对称位置还有一颗。按下去只有一个动作时，它等于"打开开始菜单"；一旦和别的键组合，它就是系统级快捷键的发令枪。

## 二、五个每天都会用到的

**Win + Shift + S：划区截屏**

按下屏幕会暗下来，鼠标变成十字，拖一个框，截图直接进剪贴板。不用打开 QQ、不用打开微信、不用先存文件再上传——`Ctrl + V` 就能贴进任何地方。

很多人装一堆截图软件，其实系统自带的这个已经够了。按下后右下角会弹通知，点进去还能简单涂改、裁剪，改完再保存。

**Win + V：剪贴板历史**

这个功能默认是关的，第一次按会提示你开启，开一次就永久有效。从此 `Ctrl + C` 不再只记住最后一次复制的内容，而是留下最近几十条，`Win + V` 一按全列出来，方向键选、回车粘贴。

写文档时在几个素材之间来回搬运，这个键能省掉大量"切窗口 → 重新复制"的动作。

**Win + D：回到桌面**

所有窗口瞬间最小化，再按一次原样恢复。临时要看一下桌面上的文件、或者有人走过来时，比一个个点最小化快得多。

**Win + E：资源管理器**

不用先回桌面找"此电脑"，直接开。配合 `Ctrl + Shift + N` 新建文件夹，整理文件的基本动作就齐了。

**Win + L：锁屏**

离开座位标准动作。比等屏幕保护、比合盖（笔记本合盖还可能只是睡眠）都快，而且立刻要求输入密码。

## 三、窗口别再手动拖了

![Win + 方向键：窗口吸附](/minimal/images/kb/win-snap.png)

以前要把两个窗口并排比对，得用鼠标小心翼翼拖边框对齐。现在：

| 按法 | 结果 |
|---|---|
| `Win + ←` | 窗口贴左半边 |
| `Win + →` | 窗口贴右半边 |
| `Win + ↑` | 最大化 |
| `Win + ↓` | 缩小 / 最小化 |

**左右吸住之后再按一次反方向键**，窗口会回到原来的大小；**贴左之后再按 `Win + ↑`**，就占住左上四分之一，接着按 `Win + →` 就是右上——四角是拼出来的。

尤其说一下 `Win + ↓`：它比最小化按钮好用，因为最小化之后窗口就"没了"，而 `Win + ↓` 会先把它缩成一个窗口，再按一次才最小化。

## 四、虚拟桌面：把工作和娱乐分开

![虚拟桌面](/minimal/images/kb/virtual-desktop.png)

**Win + Ctrl + D** 新建一张桌面，**Win + Ctrl + ← / →** 在桌面之间切换。

它的意义不是"多出几块屏幕"，而是**把窗口分组藏起来**：桌面 1 放浏览器、编辑器、终端，桌面 2 放播放器、笔记。切到桌面 2 时，桌面 1 的程序一个都不会关，继续在后台跑，只是不显示。

按 **Win + Tab** 能看到全部桌面和每个桌面上的窗口，任务栏上方也有"新建桌面"的加号。用不着的桌面可以在 Win+Tab 界面里直接删掉，上面的窗口会合并到相邻桌面。

## 五、截图这件事，系统给了三套

| 按法 | 截图去哪 | 什么时候用 |
|---|---|---|
| `Win + Shift + S` | 剪贴板 | 贴进聊天框、文档，最快 |
| `Win + PrtScn` | 自动存到「图片 / 屏幕截图」 | 要留档、要发原图 |
| `Alt + PrtScn` | 剪贴板，只截当前窗口 | 报错截图，不带上旁边的东西 |

三套里最常用的是第一套，但发现很多人不知道第二套：整屏截图不用任何软件，按下就自动落一个文件在硬盘里，文件名带时间戳。

**按了没反应怎么办**：先确认截图工具没被关（设置 → 辅助功能 → 键盘，或搜索"截图"），再检查外接键盘是不是把 F 区设成了多媒体键需要配合 Fn。笔记本上 `PrtScn` 常常和别的东西共用一颗键。

## 六、还有几个值得知道的

**`Win + 数字键`**：任务栏从左往右第 N 个程序，按 `Win + 1` 就切过去，再按一次最小化。常用的浏览器、编辑器、终端固定在任务栏前三位，这三个键位比鼠标准。

**`Win + Shift + ← / →`**：窗口不是移动半屏，而是**整个搬到另一块显示器**上。双屏办公的人必备，比拖着窗口穿过两块屏快得多。

**`Win + 空格`**：切换输入法。装了中英两套以上输入法时，这个比 `Ctrl + Shift` 或 `Shift` 稳，因为它切换的是"输入法"而不是"输入法里的语言"。

**`Win + ,`**（逗号）：**按住不放**时所有窗口变透明，能看见桌面；松手恢复。想瞄一眼桌面上的文件、又不想把所有窗口都最小化，用这个。

**`Win + Home`**：最小化除当前窗口之外的所有窗口。桌面上开了十几个窗口、只想专心看一个时，比一个个点最小化省事。

**`Win + G`**：Xbox Game Bar，能录屏、能看帧率。录一段操作演示不用装 OBS。

## 七、一张表带走

| 组合 | 作用 |
|---|---|
| `Win + Shift + S` | 划区截屏，进剪贴板 |
| `Win + V` | 剪贴板历史 |
| `Win + D` | 显示桌面 / 恢复 |
| `Win + E` | 打开资源管理器 |
| `Win + I` | 打开系统设置 |
| `Win + L` | 锁屏 |
| `Win + P` | 投影 / 多显示器模式 |
| `Win + X` | 超级用户菜单（开始按钮右键同一份） |
| `Win + ;` | Emoji 表情面板 |
| `Win + Pause` | 系统信息（可进高级系统设置） |
| `Win + Tab` | 任务视图 / 虚拟桌面管理 |
| `Win + Ctrl + D` | 新建虚拟桌面 |
| `Win + Ctrl + ← / →` | 切换虚拟桌面 |
| `Win + ↑ ↓ ← →` | 窗口最大化 / 最小化 / 吸附 |
| `Win + Shift + ← / →` | 窗口移到另一块显示器 |
| `Win + 数字键` | 切换任务栏第 N 个程序 |
| `Win + 空格` | 切换输入法 |
| `Win + ,` | 按住偷看桌面 |
| `Win + Home` | 最小化其他所有窗口 |
| `Win + PrtScn` | 全屏截图并自动存盘 |
| `Win + G` | 游戏栏 / 录屏 |

`Win + Pause` 的位置不太统一，不少笔记本和小键盘配列上根本没有这颗键，按不出来不用怀疑自己。`Win + X` 有个更方便的等价操作：**右键点开始按钮**，弹出的是同一个菜单，里面有设备管理器、磁盘管理、终端、电源选项——比在设置里翻半天快。

## 八、怎么练

别一次记十几条。挑三个当下最烦的动作换成快捷键：截图用 `Win + Shift + S`、切窗口用 `Win + Ctrl + ← →`、看历史用 `Win + V`。用顺手了再加，两周之后手指会自己记住。
