三个修饰键里，Alt 是最没存在感的一个。Ctrl 管编辑，Win 管系统，Alt 好像只剩下"关掉当前窗口"这一条被人记住。

其实 Alt 的分工很清晰：**它管的是"窗口"这一层**——在哪个窗口、切到哪个窗口、关掉哪个窗口。加上一个冷门到几乎无人使用的文字选择技巧，值得单独写一篇。

![Alt + Tab 切换窗口](/images/kb/alt-tab.png)

## 一、Alt + Tab：切窗口的正确姿势

很多人是"按一下 `Alt + Tab`，切到上一个窗口，再按一下，又切回去"——两个窗口之间来回时这样确实够用。但它的完整用法是**按住不放**：

1. 按住 `Alt` 不松手；
2. 按一下 `Tab`，屏幕中间弹出所有窗口的缩略图，选中框落在第二个；
3. 继续按 `Tab`，选中框继续往后走；
4. **松开 Alt**，切到当前选中的那个窗口。

按多了怎么办？`Alt + Shift + Tab` 是往回走，跟 `Tab` 反向。按住 Alt 的同时加 Shift，选中框就倒着转。

这个"按住不松手"的模式值得单独练几次。窗口一多，一下一下按很容易切过头，而按住不放、看着缩略图选，一次就到位。

顺便说，`Win + Tab` 是它的加强版：弹出的是任务视图，能看到所有虚拟桌面和每个桌面上的全部窗口，鼠标可以直接点。

## 二、Alt + F4：关掉当前窗口

`Alt + F4` 关闭当前活动窗口。在普通程序里等于点右上角的 ×；**在桌面上按**，弹出的是"关闭 Windows"对话框，里面有睡眠、关机、重启——不想去开始菜单翻的时候，这两下就到了。

要注意的是它关的是"当前窗口"而不是"整个程序"。浏览器开了十个标签页，`Alt + F4` 关掉的是窗口本身（会问你十个页签要不要一起关），而 `Ctrl + W` 关的只是一个页签。这两个键经常被混用，记住这点就不会误关。

## 三、那个几乎没人知道的用法：Alt + 拖选链接文字

网页上到处都是超链接。想复制链接文字本身（不是链接地址）的时候，直接拖选会出问题——鼠标一按下去就变成"拖拽链接"，选不中文字，松手还可能把链接拖到别处打开。

**按住 `Alt` 再拖选**，就绕开了拖拽行为，可以像选普通文字一样选中链接里的字。

这个用法在"想引用某篇文章标题""复制导航栏里的栏目名"时特别顺手，知道的人很少。浏览器里通用，Edge、Chrome 都行。

## 四、还有几个都在"窗口"这一层

| 组合 | 作用 | 什么时候想起它 |
|---|---|---|
| `Alt + Enter` | 查看属性 | 看文件大小、路径、图片尺寸 |
| `Alt + 空格` | 窗口控制菜单 | 窗口跑到屏幕外、鼠标够不到标题栏 |
| `Alt + Esc` | 直接轮换窗口 | 不弹缩略图，纯键盘循环 |
| `Alt + PrtScn` | 只截当前窗口 | 报错截图，不带上旁边的聊天窗口 |
| `Alt + Shift` | 切换输入法语言 | 中英日多语混排时 |

重点说 **`Alt + 空格`**。这是 Windows 里最"古老"的一批快捷键之一：按下后在窗口左上角弹出一个小菜单，里面有还原、移动、大小、最小化、最大化、关闭。听起来没用，值钱的地方在于**窗口被拖到屏幕外、标题栏看不见的时候**：按 `Alt + 空格`，再按 `M`（移动），然后用方向键把窗口挪回来。这个场景一生中总会遇到几次，到时候就知道有多救命。

`Alt + Enter` 也值得记：选中一个文件按它，属性面板直接出来；在命令行里按它则是切换全屏。

## 五、Alt 与其他键的关系

三个修饰键可以叠着用，叠加的顺序基本是"Win 管系统 → Ctrl 管编辑 → Alt 管窗口"：

| 组合 | 归属 | 作用 |
|---|---|---|
| `Win + Alt + R` | 系统级 | 录制当前窗口（Xbox Game Bar） |
| `Ctrl + Alt + Z / W` | 软件注册的全局热键 | 唤出 QQ / 微信 |
| `Alt + Tab / Alt + F4` | 窗口 | 切换 / 关闭 |
| `Alt + 方向键` | 软件内 | 前进后退（浏览器、资源管理器） |

`Alt + ←` 和 `Alt + →` 是浏览器的"后退 / 前进"，在资源管理器里也是"返回上一级 / 进入下一级"。习惯之后，比去点左上角那个小箭头快得多。

## 六、三条就够的练习清单

1. 下次切窗口，**按住 Alt 别松**，连按 Tab 看缩略图，松开手；
2. 用 `Alt + F4` 关一个不用的窗口，代替去点右上角的 ×；
3. 找一条网页上的链接，按住 `Alt` 拖选它的文字，再 `Ctrl + C` 试试。

三条都做到，Alt 就不再是键盘上那颗"不知道干嘛用"的键了。
