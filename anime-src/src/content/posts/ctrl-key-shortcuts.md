`Ctrl + C` 和 `Ctrl + V` 大概是所有人学会的头两个快捷键，然后就没有然后了。可 Ctrl 是键盘上组合最密集的修饰键，几乎所有"在当前软件内生效"的操作都挂在它下面。

这篇按**用途分组**，不按字母排。同一组里的键一起记，用的时候能想起来。

![Ctrl 组常用快捷键](/anime/images/kb/ctrl-keys.png)

## 一、选中与删除：先把"批量"这件事做掉

| 组合 | 作用 |
|---|---|
| `Ctrl + A` | 全选 |
| `Ctrl + 点击` | 一个一个挑着多选 |
| `Shift + 点击` | 选中一段连续的区间 |
| `Ctrl + D` | 删除选中项（在资源管理器里） |

`Ctrl + A` 之后再按 `Backspace`，是清空输入框最快的办法——比按住退格键等它一个个删快得多，也不会误删掉一半就停手。

在资源管理器里选文件，Ctrl 和 Shift 是两套逻辑：`Ctrl + 点击` 是**散着挑**，点错了再点一次就取消；`Shift + 点击` 是**成段选**，先点第一个，再点最后一个，中间全选上。删一堆文件时先 Shift 选个大范围，再用 Ctrl 把不要的剔出去，比逐个点快太多。

## 二、找与换：文档变长之后的分水岭

`Ctrl + F` 是查找，页面右上角或者底部会弹出一个框，输入关键词就能定位。文档一长、网页一长，肉眼翻就是浪费时间；它还能用来"确认某句话在不在这篇文章里"。

`Ctrl + H` 是替换。它不是查找的加强版，而是**批量改写的入口**：把"公司"全部换成"集团"，把一堆写法不统一的标点一次性统一。改文档、改代码、改表格都用得上。

`Ctrl + P` 是打印，顺带也是"导出 PDF"最通用的入口——Windows 自带的"Microsoft Print to PDF"就在打印机列表里。

## 三、手滑之后的后悔药

`Ctrl + Z` 撤销，`Ctrl + Y` 恢复（把撤销掉的操作再做回来）。

这两个键拯救过所有人。要注意的是**撤销的深度有限**：Office 能退几十步，很多小程序只留几步，网页表单基本没有。改重要文件之前先 `Ctrl + S`，比事后找撤销可靠。

部分软件里"恢复"不是 `Ctrl + Y`，而是 `Ctrl + Shift + Z`（尤其是各种编辑器）。按不出来就查一下软件的快捷键说明，别硬记。

## 四、写东西时的格式键

`Ctrl + B` 加粗、`Ctrl + I` 斜体、`Ctrl + U` 下划线。

这三个在 Word、WPS、Obsidian、各类笔记和富文本编辑器里基本通用。写文档时不必去点工具栏的小图标，手不用离开键盘，敲完接着打字，光标不会跳走。

## 五、保存、标签页与缩放

| 组合 | 作用 |
|---|---|
| `Ctrl + S` | 保存 |
| `Ctrl + Tab` | 切到下一个标签页 |
| `Ctrl + W` | 关闭当前标签页 |
| `Ctrl + 滚轮` | 放大 / 缩小页面 |

`Ctrl + S` 应该变成肌肉记忆，尤其是写代码和写长文的时候——养成每隔几分钟按一次的习惯，比相信"软件会自动保存"踏实。

浏览器开二三十个标签页的人，`Ctrl + Tab` 比用鼠标去点那一排小页签准得多，`Ctrl + W` 关页签也快。注意别在没保存的编辑器里按它，有的软件关标签页会连窗口一起关。

`Ctrl + 滚轮` 缩放的是**页面**而不是系统（系统缩放是 `Win + 加号`）。看小字网页特别有用。

## 六、新建与唤出

`Ctrl + Shift + N` 在资源管理器里新建文件夹，这是每天用得最多的组合之一。同样三个键在浏览器里是"新建无痕窗口"，在不少笔记软件里是"新建笔记"——**修饰键一样，动作随软件变**，这是快捷键的通用规律。

`Ctrl + Alt + Z` 唤出 QQ / TIM，`Ctrl + Alt + W` 唤出微信。这两个是软件自己注册的全局热键，不管你在干什么都能把窗口拉到最前。被人打断、回头要找聊天窗口时，比去任务栏翻快。

## 七、把刚关掉的页面找回来

这可能是 Ctrl 里最"救命"的一个：**`Ctrl + Shift + T`**。

浏览器里误关了标签页，按一下就回来，连按几下能把一串关掉的页签按倒序全部恢复。更妙的是它恢复的是**整个会话状态**：表单里没提交的内容、滚到的位置，都还在。

同三个键在资源管理器里是"撤销上一次删除/重命名"，刚手滑清掉的文件，用这个比去回收站翻快。

**`Ctrl + Shift + Esc`**：一步打开任务管理器。软件卡死、风扇狂转、要给开机项提速的时候用这个，比 `Ctrl + Alt + Del` 再点"任务管理器"少两步。

**`Ctrl + Shift + V`**：无格式粘贴。从网页往文档里粘东西，默认会带上字体、颜色、行距，粘完还得手动清格式；这个键只粘纯文本。支持它的软件不少（浏览器地址栏、多数笔记、部分聊天窗口），但**不是所有软件都认**，Word 里对应的是"选择性粘贴"。

## 八、几个"少按很多次键"的编辑动作

| 组合 | 作用 |
|---|---|
| `Ctrl + Backspace` | 删掉前一个词 |
| `Ctrl + Delete` | 删掉后一个词 |
| `Ctrl + ← / →` | 光标按词移动 |
| `Ctrl + Home / End` | 跳到文首 / 文末 |
| `Ctrl + L` | 定位到地址栏 |
| `Ctrl + Shift + S` | 另存为 |

`Ctrl + Backspace` 值得单独练：打错一长串英文变量名的时候，一下删一整个词，比按住退格键一格一格退快得多，而且不会退过头把上一句也吃掉。

`Ctrl + Home` 是把光标送到文首——一篇长文档里想回去改开头，不用一路滚轮往上翻。

`Ctrl + L` 在浏览器里把焦点送进地址栏并全选当前网址，直接打字就是新地址，不用先用鼠标点一下再 `Ctrl + A`。

## 九、一张表带走

| 组合 | 作用 |
|---|---|
| `Ctrl + A` | 全选 |
| `Ctrl + 点击 / Shift + 点击` | 散选 / 连选 |
| `Ctrl + D` | 删除（资源管理器） |
| `Ctrl + Shift + N` | 新建文件夹 |
| `Ctrl + F` | 查找 |
| `Ctrl + H` | 替换 |
| `Ctrl + Z / Ctrl + Y` | 撤销 / 恢复 |
| `Ctrl + B / I / U` | 加粗 / 斜体 / 下划线 |
| `Ctrl + S` | 保存 |
| `Ctrl + P` | 打印 / 导出 PDF |
| `Ctrl + Tab / Ctrl + W` | 切标签页 / 关标签页 |
| `Ctrl + 滚轮` | 页面缩放 |
| `Ctrl + Alt + Z / W` | 唤出 QQ / 微信 |
| `Ctrl + Shift + T` | 恢复刚关掉的标签页 / 撤销删除 |
| `Ctrl + Shift + Esc` | 打开任务管理器 |
| `Ctrl + Shift + V` | 无格式粘贴 |
| `Ctrl + Backspace` | 删除前一个词 |
| `Ctrl + ← / →` | 光标按词移动 |
| `Ctrl + L` | 定位到地址栏 |

真的不用一次全记。先把 `Ctrl + S` 和 `Ctrl + Z` 变成条件反射，这两个决定了你会不会丢东西；再补 `Ctrl + F`，它决定了你找东西的速度。剩下的，用到哪个查哪个，查两三次就记住了。
