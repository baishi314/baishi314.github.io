## 快速配置

**前提**：Windows 10 及以上、能联网、有管理员权限。

1. 开始菜单搜 Word，能打开且「文件→账户」显示已激活 → 直接跳到[第6步](#第6步-检查是否正常使用)，后面的都别做。
2. 打开 https://otp.landian.vip/zh-cn/download.html ，点 **64 位版本**，**完整解压**到桌面，右键 `OfficeToolPlus.exe` 以管理员身份运行。
3. 左侧 **部署**：产品选 `Microsoft 365` 或 `Office 2021/2024 批量版` → 架构 `64 位` → 语言 `zh-cn` → 勾 Word、Excel、PowerPoint → **开始部署**，等 10～30 分钟。
4. 左侧 **激活**：先点 **清除激活信息**，再点 **重置 Office 设置**。
5. 在激活页安装批量版许可证、KMS 管理填主机、点激活；熟了以后可以用 `Ctrl + Shift + P` 一条命令搞定，或者走账号、密钥、学校地址。
6. Word → 文件 → 账户，显示「已激活」即完成。

## 第0步 检查电脑上已有的 Office

新电脑不一定是空的。品牌机常预装 Office 家庭学生版，二手电脑里也可能留着半残的旧版。**先看清现状，能省掉一半麻烦。**

**怎么查**

1. 开始菜单搜 `Word`。能打开 → 点 **文件 → 账户**，看产品信息那行写的是什么（已激活 / 需要激活 / 试用）。
2. 控制面板 → **程序和功能**，找这些名字：`Microsoft 365`、`Office 2021`、`Office 2019`、`Office 16 Click-to-Run`、`WPS Office`。
3. 想看得更准，用管理员 PowerShell 跑一句：

   ```powershell
   cscript "C:\Program Files\Microsoft Office\Office16\OSPP.VBS" /dstatus
   ```

   能看到许可证名称、状态、剩余天数，比界面显示的更可信。

**查完怎么判断**

| 电脑现状 | 该做什么 |
|---|---|
| 已有 Office，且显示已激活 | **跳过安装**，直接[第6步](#第6步-检查是否正常使用)验证 |
| 有 Office 但提示未激活 / 试用已过期 | 先看是不是账号没登（登一下就好）；确实没授权再往下装 |
| 预装的「Office 家庭学生版」提示需要激活 | 这台机器多半带绑定账号的授权，登录当初绑定的微软账号即可；账号记不得就重装 |
| 装着旧版 2016/2019，想换新版 | **先卸载再装**，新旧共存是后面各种怪问题的头号来源 |
| 装着 WPS | 两者能共存，但文件默认打开方式会被抢。装完 Office 后在「默认应用」里改回来 |
| 干干净净，什么都没有 | 从[第2步](#第2步-下载-office-tool-plus)开始 |

**做到什么样算成功**：你明确知道这台电脑"有没有 Office、什么版本、激活没激活"。这三个问题答不上来，先别急着下载。

## 第1步 分清安装与激活

这一步只用记住一句话：**安装是把文件铺到硬盘上，激活是让 Office 相信这台机器有使用许可。**

- 只装不激活：Word 能打开，但顶部挂黄条、部分功能灰掉、可能只能看不能改。
- 装完激活：功能全开，黄条消失。

所以「装 Office」和「激活 Office」是两个独立动作，出问题时也要分开排查——装不上是文件和权限的事，激活不了是许可证和网络的事，八竿子打不着。

许可从哪来，一共四类：

| 来源 | 谁有 | 大概长什么样 |
|---|---|---|
| **微软账号** | 买了 Microsoft 365 订阅的人 | 打开 Word 登录即激活，跟着账号走，换电脑也能用 |
| **产品密钥** | 买断版（2021/2024 零售） | 25 位字符，一组 5 位，输一次绑设备或账号 |
| **学校/单位 KMS** | 在校师生、在职员工 | 一串服务器地址，连着内网才能用，定期自动续期 |
| **批量授权 / 其它手段** | 见[附录 A](#附录-a-备用-kms-与破解类手段) | 命令、KMS 地址、或第三方工具 |

前三种是正规路子，[第5步](#第5步-激活)按这三条走。原理细节放[附录 B](#附录-b-术语速查)，现在不用管。

## 第2步 下载 Office Tool Plus

官网：https://otp.landian.vip/zh-cn/download.html

**选哪个包**

| 情况 | 选择 |
|---|---|
| 常见的 64 位 Windows 10/11 | **64 位版本**（默认，闭眼选这个） |
| 骁龙 / ARM 笔记本 | Arm64 版本 |
| 老 32 位系统 | 32 位版本 |
| 硬盘紧张、网速慢 | 7z 压缩包版，或「不含运行时的版本」 |

当前最新是 v11（2026/10/18 发布）。**v10** 留给跑不动最新版的系统，**v9** 专给 Windows 7 SP1。官方写的系统要求是 Windows 10 / Server 2016 起。

**下载源**：页面给了夸克网盘、山大、上交、南大、兰大等镜像，还有 GitHub、SourceForge。官方源慢就换镜像，文件一样。也支持命令行安装：

```powershell
winget install Yerong.OfficeToolPlus      # 需管理员权限
irm https://officetool.plus | iex         # PowerShell 一键脚本
```

**两个别偷懒的地方**

- **完整解压**再运行，别在压缩包里直接双击，否则缺文件、报错、闪退都来了。
- **右键以管理员身份运行**，部署要往系统目录写东西，权限不够会中途失败。

**做到什么样算成功**：解压后看到 `OfficeToolPlus.exe`，双击能出主界面，左侧有「部署 / 激活 / 工具箱」。

## 第3步 选择版本和组件

左侧 **部署** 页，从上往下填。这一步选错，后面激活会跟着错，所以慢一点。

**产品（最关键）**

| 你手上的许可 | 该选 |
|---|---|
| Microsoft 365 订阅 | `Microsoft 365` |
| 买断版密钥（2021/2024 零售） | `Office 2021` 或 `Office 2024`（零售） |
| 学校/单位的 KMS | `Office 2021/2024 批量版`，或 `Microsoft 365` |
| 什么都没有，只想先用起来 | `Microsoft 365` + 附录 A |

**判断口诀**：零售版配密钥，批量版配 KMS。装零售版却拿 KMS 去激活，一定失败；反过来也一样。产品名后面带「批量版 / Volume」字样的就是批量版。

**架构**：64 位。除非是很老的机器或特殊插件要求 32 位，否则不用犹豫。

**通道**：默认即可。365 选「当前通道」，买断版按版本选对应通道。

**语言**：简体中文 `zh-cn`。有外文需求可再加一个英文语言包，不占额外安装步骤。

**组件**：只勾你要用的。

- 学生/日常：Word、Excel、PowerPoint。
- 办公加邮件：再加 Outlook。
- 工程/项目管理：单独勾 Visio、Project（这两个算独立产品，许可也分开）。
- Access、Publisher、OneNote：不用就别勾，省空间也省事。

**做到什么样算成功**：部署页顶部那行「待安装」摘要，产品、架构、语言、组件四项都对得上你的预期。

## 第4步 安装

1. **先清场**：如果第0步查出有旧版 Office，回部署页用 **卸载** 功能清干净，再往下。
2. 按第3步填好部署页。
3. 点 **开始部署**，弹确认框点「是」。
4. 等。10～30 分钟，取决于网速。期间别断网、别休眠、别点取消。
5. 看到「部署完成」提示，关掉工具。

**做到什么样算成功**：开始菜单出现 Word、Excel、PowerPoint 图标，能点开窗口（此时可能提示未激活，属于正常，下一步解决）。

**顺带说一句**：C 盘紧张的话，部署前在「安装设置」里改安装位置，装完再挪很麻烦。

## 第5步 激活

旧许可要先清掉，否则新旧信息会打架：**激活** 页 → **清除激活信息** → 再点一次 **重置 Office 设置**。

### 方式 A 手动点界面（新手走这条）

不用敲命令，点几下就行：

1. 左侧 **激活** 页，找 **许可证管理**，点 **安装许可证**。
2. 列表里选带 **Volume（批量）** 字样的那项，比如 `Office 2021 批量版`、`Microsoft 365`。挑错版本会激活失败，按你在第3步装的产品对应着选。
3. 找 **KMS 管理**，主机地址填 `kms.loli.best`，端口填 `1688`，点 **保存设置**。
4. 回页面顶部点 **激活**。
5. 等进度条走完，出现「激活成功」或产品信息变成「已激活」。

**怎么确认选对了许可证**：激活页顶部会显示当前许可证名称，和你装的产品版本要对得上。装了 Microsoft 365，许可证那行就该是 Mondo 或 365 相关的名字；看着像 2016、2019 就是挑错了，重新装许可证。

**卡住了怎么办**：先看状态是不是「已激活」，再把[第6步](#第6步-检查是否正常使用)那三条验证走一遍。还是不行就换方式 B 的命令，命令会顺手清理旧许可，比手动点更彻底。

### 方式 B 自动激活（一条命令，省事）

按 `Ctrl + Shift + P` 打开命令框，按你的产品粘贴：

**Microsoft 365 / 不确定装了什么**

```
ospp /unlics /unkeys /inslicid MondoVolume /sethst kms.loli.best /setprt 1688 /act
```

**Office 2024 批量版**

```
ospp /inslicid ProPlus2024Volume /sethst kms.loli.best /setprt 1688 /act
```

**Office 2021 批量版**

```
ospp /inslicid ProPlus2021Volume /sethst kms.loli.best /setprt 1688 /act
```

**Office 2019 批量版**

```
ospp /inslicid ProPlus2019Volume /sethst kms.loli.best /setprt 1688 /act
```

**Office 2016 批量版**

```
ospp /inslicid ProPlusVolume /sethst kms.loli.best /setprt 1688 /act
```

Visio 把 `ProPlus` 换成 `VisioPro`，Project 换成 `ProjectPro`，年份照抄。

命令拆开看：`/inslicid` 装哪个许可证，`/sethst` 填 KMS 主机地址，`/setprt 1688` 是端口，`/act` 才真正发起激活。前面那句 `ospp /unlics /unkeys` 是顺手清掉旧许可和旧密钥，所以这条比方式 A 更不容易留后遗症。

### 方式 C 你自己的正版

**有 Microsoft 365 订阅**：打开 Word，右上角登录微软账号，等几秒黄条自己消失。订阅跟着账号走，换电脑也一样。

**有买断版密钥**：Word → **文件 → 账户** → **更改产品密钥**（有的版本叫「激活产品」）→ 输入 25 位密钥，一组 5 位。提示激活成功即可。

### 方式 D 学校或单位提供的正版化

在校师生走这条最稳。

**学校在支持名单里**（上交、清华、北大、南大、中科大、重大、中央民族等）：在**校园网内**运行 Office Tool Plus，主页直接出现「一键安装」「一键激活」按钮，点一下即可。

**学校买了正版化但没进名单**：去学校软件中心或信息化办的页面找 Office 正版化那一条，通常会给一个 KMS 地址。拿到后在 **激活** 页安装批量版许可证、KMS 管理里填地址（端口一般 `1688`）、保存、点激活。

**人在校外**：KMS 只在内网放行，先连学校 VPN，再重复上面步骤。

部分高校 KMS 地址（网友整理，可能变动，以学校官方为准）：北大 `kms.pku.edu.cn`、清华 `kms.cic.tsinghua.edu.cn`、上交 `kms.sjtu.edu.cn`、南大 `219.219.115.74`、中科大 `kms.ustc.edu.cn`、复旦 `mvls.fudan.edu.cn`、同济 `kms.tongji.edu.cn`、中山 `kms.sysu.edu.cn`、河南科技大学 `kms.haust.edu.cn`、华南理工 `act.msweb.scut.edu.cn`。

### 关于 KMS 的两个事实

- KMS 只对**批量授权**有效，零售许可证接不上。所以第3步选产品时就得选批量版。
- 激活成功后 Office 每 7 天向 KMS 主机续一次，只要主机和网络正常就会自动续期，不存在「180 天到期」这回事。主机不可用时，换个地址重设即可，不用重装 Office。

## 第6步 检查是否正常使用

激活提示成功不等于真能用。三步验证，缺一不可：

1. **看状态**：Word → 文件 → 账户 → 产品信息，应显示「已激活」（或「已订阅」）。
2. **看实操**：新建空白文档，打几个字，另存为 `.docx`，关掉再打开，内容还在。
3. **看组件**：Excel 能新建表格、PowerPoint 能新建幻灯片，顶部没有「试用 / 购买」横幅。

三条都过才算收工。只过第 1 条要当心——界面显示已激活、双击却弹出查看器的情况真存在，多半是许可证模式选错了（装的是 365 却挂了 2021 的许可，或者反过来）。这种情况不用重装，回激活页换对许可证再来一次。

## 常见问题对照表

| 现象 | 原因 | 处理 |
|---|---|---|
| 点「下载」跳回 download.html | 按钮是跳转型 | 直接点「64 位版本」几个字，或换镜像站 |
| 双击 exe 毫无反应 | 解压不完整、缺 .NET 运行时、系统版本偏低 | 重新完整解压；换含运行时的包；Win7 用 v9 |
| 提示连接 `127.0.0.1:7890` 被拒绝 | 电脑上开着代理软件但没启动，或已退出 | 关掉系统代理，或把代理软件正常打开再试 |
| 部署时弹窗提示获取 Office 版本出错 | 同上，网络被代理拦了 | 清代理重试，或把下载引擎切成 Office 部署工具 |
| 部署完成，打开仍提示未激活 | 装的是零售版，挂的许可证不匹配 | 重装成批量版，或换对应许可证 |
| 显示已激活，打开 Excel 却是查看器 | 许可证模式不对；方式 A 挑许可证时选错了版本 | 更新工具到最新版，激活页会提示许可模式，按提示改 |
| 激活报错 `0x80080005` | 系统的 Software Protection 服务异常 | 重启电脑；`services.msc` 里把它设为自动并启动 |
| 装完 C 盘爆满 | 默认装在系统盘 | 部署前在安装设置里改路径 |
| 装完双击文档仍用 WPS 打开 | 文件关联被 WPS 抢了 | 设置 → 默认应用 → 按文件类型改回 Word/Excel |

**一条总原则**：激活出问题，先查步骤和网络，重装 Office 是最后手段，多数时候纯属白花时间。

## 附录 A 备用 KMS 与破解类手段

方式 B 已经贴过完整命令，这里只放两件事：换主机，和破解类手段的定位。

**换个 KMS 主机**：正在用的主机失效时，激活页把地址改掉、重新保存、再点激活即可，许可证不用重装。可用地址的实时状态表在 https://blog.yerong.org/archives/14

**破解类手段**（简述，供理解差异）：Ohook 劫持系统 Software Protection 服务返回的结果，让所有许可证显示已激活；TSforge 伪造密钥与确认 ID 写进激活令牌。两者都没动 Office 文件本身，但一个改了系统工作流程、一个伪造了授权数据。技术上都能让 Office 跑起来，性质上是破解或盗版。

## 附录 B 术语速查

- **Office Tool Plus**：Office 部署工具的图形界面，下载的是微软原版安装包，本身不修改 Office。它只解决「装」，不解决「授权」。
- **零售版 / Retail**：面向个人买断的授权形态，配密钥或账号。
- **批量版 / Volume**：面向企业和学校的授权形态，配 KMS。
- **KMS**：企业批量激活机制，客户端定期向 KMS 主机报道续期。学校买的正版化走这条，网上公开的 KMS 服务器则是另一回事。
- **ODT**：微软官方的 Office 部署工具，命令行版，Office Tool Plus 的底座。
- **通道（Channel）**：更新节奏，当前通道、月度企业通道等，决定你多久收到一次功能更新。
- **`ospp.vbs`**：系统自带的 Office 激活管理脚本，命令行里那些 `ospp` 命令最终都调它。
- **0x80080005**：Windows 里常见的「服务器运行失败」，Office 激活时出现基本都指向 Software Protection 服务。
